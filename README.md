# University Performance Dashboard 🎓📊

This Power BI project provides a detailed analysis of a university's performance across various dimensions such as students, departments, faculty, courses, and exams.

---

## 🚀 Features

- *Page 1: Overview*
  - KPIs: Total Students, Total Courses, Exams, Avg Marks, Pass Rate
  - Gender Distribution & Year-wise Trends

- *Page 2: Department-Wise Analysis*
  - Avg Marks by Department
  - Pass Rate, Total Students
  - Gender-wise & Exam-wise breakdown

- *Page 3: Faculty Performance*
  - Faculty Count
  - Avg Experience
  - Department-wise Faculty Distribution

- *Page 4: Student Performance*
  - Count of Students by Gender, Year
  - Avg Marks by Year & Gender
  - Pass/Fail Breakdown

- *Page 5: Exam & Course Analysis*
  - Courses with Exams
  - Exam Type Distribution
  - Course-wise Avg Marks
  - Year-wise Exam Trend
